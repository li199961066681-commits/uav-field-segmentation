# 无人机农田图斑分割与边界校验

> 纯 OpenCV 实现，无深度学习依赖 —— 从无人机正射影像中逐块提取农田图斑（多边形），替代人工勾画。

![Python](https://img.shields.io/badge/Python-3.x-blue) ![OpenCV](https://img.shields.io/badge/OpenCV-4.x%2F5.x-green)

---

## 项目简介

输入是无人机低空正射影像（单幅约 2048×1050 px，可见矩形田块 + 机耕道 + 沟渠），输出是每块田的边界多边形与叠加图。
传统 CV 方案在**固定场景**（同一地区、同一季节）下已够用；跨地区/跨季节大规模影像才需要深度学习。

难点在于：相邻田块颜色几乎一致（同为熟稻或同为青苗），只靠颜色阈值 + 闭运算清理，会把相邻田块**糊成一个轮廓**。

## 处理流程

```
影像 → ① 农田候选掩膜（HSV 色域 + 局部纹理标准差）
     → ② 分割屏障（均值漂移梯度 + 自适应 Canny + 道路/沟渠色彩规则）
     → ③ 掩膜减屏障 → 开运算去碎点
     → ④ 连通域 + 逐块内部补洞 → 面积/矩形度/凸实度/纹理过滤
     → ⑤ approxPolyDP 简化 → 画红线 / 导出 labelme JSON
```

核心思路一句话：**先找缝，再切田**。田埂/机耕道/沟渠是天然的缝，把缝抹粗几像素作为屏障，剩下的农田自然被切成一块块。

## 关键技术点

| 环节 | 做法 | 为什么 |
|---|---|---|
| 农田筛选 | HSV `H∈[12,70]`、`S≥45`、`V∈[42,240]` | 覆盖青绿稻 → 枯黄稻/麦茬；排除灰路、阴影 |
| 纹理门限 | 15×15 窗口局部标准差 `> 26` 剔除 | 树带、屋顶、机耕道纹理跳变，田块平滑 |
| 主力边界线索 | 1/2 分辨率 `pyrMeanShiftFiltering(sp=8, sr=30)` 后取 Lab 三通道最大 Sobel 梯度，按 88 分位取阈值 | 抹平作物行纹理，保留**田块之间的色调断层**；分位阈值换图不用重调 |
| 辅助边界线索 | 降采样 Canny，阈值取梯度 92 分位 | 作物行纹理在低分辨率消失，真田界还在 |
| 屏障规则 | `S<60 且 V>145`（机耕道）、`V<52`（沟渠/阴影） | 补充颜色上的硬边界 |
| 形态学 | 开运算 5×5 去碎点；**单块内部** 11×11 补洞 | 大核全局闭运算会把 3~6 px 宽的田埂一起焊死 |
| 图斑过滤 | 面积占比 ≥0.18%、矩形度 ≥0.5、凸实度 ≥0.6、内部标准差 ≤26、被大块包住的碎片丢弃 | 去掉碎块、细长条、锯齿形假图斑、重复套叠 |
| 轮廓输出 | `approxPolyDP(eps = 0.01 × 周长)` | 压掉锯齿同时保留拐角 |

### 踩过的坑（勿重复）

- **9×9 闭运算**：把 3~6 px 的田埂焊接，覆盖率高但田块粘连，正是「几块田画成一个轮廓」的根因。
- **定向闭运算搭桥（15/23 px + 四方向 line kernel）**：屏障被糊成整片黑，覆盖率 0.51 → 0.25，图斑碎裂，弃用。
- **Hough 长直线切割**：分数从 0.605 升到 0.682，但田块出现锯齿咬口与田内假轮廓（割晒条纹被当成边界），加 Lab 色差校验后反而降到 0.619，弃用。
- **分水岭 split_big**：裁剪粒度过粗，对无收窄的粘连块无效，简化版中移除。
- **tophat/blackhat 细线增强**：在均值漂移梯度已生效时贡献为零，关闭。

## 运行

```bash
pip install -r requirements.txt
python uav_demo.py          # 自动读取同目录下的 png/jpg，输出到 output/
```

输出：`output/overlay_<图片名>.png`（原图 + 红线图斑）。

实测结果：

| 影像 | 图斑数 |
|---|---|
| 1.png（矩形田块 + 机耕道） | 15 |
| 2.png | 18 |

## 标注与校验（labelme）

脚本可预分割，再交给 labelme 人工复核，形成「算法预分割 + 人工修边界」的半自动流程：

```bash
labelme data/1.png          # 逐块比对原图修正边界，导出 JSON
```

本仓库 `annotations/` 下为人工完善后的标注（labelme 原生 JSON，与 `data/1.png`、`data/2.png` 一一对应）。
生产用法：脚本输出候选多边形 → 导入 labelme → 人工只改错的边界 → 导出 JSON → 回写数据库做图斑台账与面积统计。
